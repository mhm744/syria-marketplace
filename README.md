# سوق سوريا - Syria Marketplace

منصة تجارة إلكترونية كاملة (B2B) شبيهة بعلي بابا للسوق السوري

## المميزات
- 🌐 موقع ويب متقدم (React/Next.js)
- 📱 تطبيق Android (Flutter)
- 💳 نظام دفع آمن
- 🔍 محرك بحث قوي
- 👥 إدارة المتاجر والمنتجات
- 📊 لوحة تحكم إحصائيات

## البنية الأساسية
```
/
├── web/           # موقع الويب (React/Next.js)
├── mobile/        # تطبيق Android (Flutter)
├── backend/       # الخادم (Node.js/Express)
└── docs/          # التوثيق
```

## البدء السريع

### موقع الويب
```bash
cd web
npm install
npm run dev
```

### تطبيق الموبايل
```bash
cd mobile
flutter pub get
flutter run
```

### البناء إلى APK
```bash
flutter build apk --release
```
